# UAMS

University Administration Management System (UAMS) is a web-based platform designed to centralize and simplify the management of university academic and administrative activities.

## Project Structure

```text
├── frontend/
│   └── README.md
│
├── backend/

│
├── database/
│   └── README.md
│
├── docs/
│   └── README.md
│
├── .gitignore
├── README.md
└── LICENSE
```

## Modules

- Student management
- Faculty and staff management
- Course and timetable management
- Fees and finance tracking
- Attendance and academic records
- Admissions and enrollment workflows
- Reports and dashboards

## Tech Stack

- Frontend: Next.js + React
- Backend: Node.js API
- Database: Supabase / PostgreSQL
- Documentation: Project docs and architecture notes

## Getting Started

1. Set up the frontend application in `frontend/`
2. Set up the backend API in `backend/`
3. Configure the database schema in `database/`
4. Add project documentation in `docs/`
